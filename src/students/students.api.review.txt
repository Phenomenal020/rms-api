EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
The students module provides org-admin CRUD-ish student management: list students,
create, PATCH details/class, GET enrollments by class+term, POST save subject
enrollments (diff insert/delete).

Strengths: OrgAdminGuard on controller; create/saveEnrollment use
runWithDbContext('student'); create validates classId in org; saveEnrollment
validates assignment IDs against class/term; enrollment diff pattern sound;
PATCH uses partial update object; gender @Transform to uppercase.

Main gaps: (1) updateStudent returns undefined when classId unchanged — critical
bug; (2) getStudents uses member join not requireOrganizationId direct filter;
(3) getEnrollments/saveEnrollment lack requireTermInOrganization and class org
validation; (4) getStudents/getEnrollments no runWithDbContext; (5) status DTO
ACTIVE/INACTIVE vs schema SUSPENDED; (6) no @MaxLength(128) on names; (7)
console.log in saveEnrollment; (8) delete enrollment with assessments → 23503
not mapped for 'student'; (9) createStudent no .returning(); (10) no
LoggingInterceptor; (11) classHistory / class change audit TODO incomplete.
